## 十四、四十一，再一次

你沒有開車回家。

你沿著卡本特高速公路開回來，暖氣開著，車窗關著，兩隻手都放在方向盤上，天際線在前方升起，像它一向那樣，而你還是看了。到了辦公室，停車場的柵欄為你的識別證抬起來。大廳的警衛是另一個人，抬起兩根手指，你也抬起兩根。

電梯從停車場的最底層載你上去，四十五層，你的耳朵做了那件事。整層樓是暗的。你一走進去，感應器就在你前面一排一排把燈喚醒，於是你在一座移動的小光島裡穿過辦公室，跟星期二相反，星期二它們是在你身後把它哄睡的。你的桌子還在你離開它的地方。窗台上，接收器每秒閃一次。

你坐下，打開筆電，把那一片叫出來。

它靜著。前沿零。東邊兩個結，往反方向轉。紀錄的最上面，在 19:15 寫著*靜*的那一筆底下，還有一筆。

```
10-30 21:00:00  預期    N→NE 重型機 爬升中  時窗 21:15–21:45
```

你看向窗外。城市銳利而冷，一路延伸到它的邊緣。高速公路朝你的是白，離你的是紅。遠處，歐文再過去，機場亮著它黯淡的琥珀色，而燈現在從南邊進來，連成一列耐心的隊伍，每一盞都是某個人，有人接，或者沒有。

21:52，一盞燈從琥珀色裡升起，慢慢地，重型機都是這樣，往北爬升，然後開始長長地往東轉，朝大西洋，朝一座它到的時候這裡天還黑著的城市。你一路看著它，直到它成為群星之中的一顆星，然後不是了。你底下四十五層，在一間沒人要的房間裡，風扇吸了一口氣又降下去。筆電上，一筆閉合了。

```
10-30 21:52:31  預期    應驗  +22 分
10-30 21:52:32  靜
```

它知道有重型機在它的時窗內往東北爬升離場。它知道的就這些。你也是。

這是一個星期五。這是錯開那一週的最後一夜。星期天兩點會又變回一點，而你會在那個房間裡，它也會。在那之前，沒有什麼該來。在上面這裡，你一停下來不動，燈就會自己熄掉，而你有好一陣子沒有停。
