## 十四、四十一，再一次

你没有开车回家。

你沿着卡彭特高速公路开回来，暖气开着，车窗关着，两只手都放在方向盘上，天际线在前方升起，像它一向那样，而你还是看了。到了办公室，停车场的道闸为你的工牌抬起来。大厅的保安是另一个人，抬起两根手指，你也抬起两根。

电梯从停车场的最底层载你上去，四十五层，你的耳朵做了那件事。整层楼是暗的。你一走进去，传感器就在你前面一排一排把灯唤醒，于是你在一座移动的小光岛里穿过办公室，跟星期二相反，星期二是在你身后把它哄睡的。你的桌子还在你离开它的地方。窗台上，接收器每秒闪一次。

你坐下，打开笔记本电脑，把那一片叫出来。

它静着。前沿零。东边两个结，往反方向转。记录的最上面，在19:15写着*静*的那一笔底下，还有一笔。

```
10-30 21:00:00  预期    N→NE 重型机 爬升中  时窗 21:15–21:45
```

你看向窗外。城市锐利而冷，一路延伸到它的边缘。高速公路朝你的是白，离你的是红。远处，欧文再过去，机场亮着它黯淡的琥珀色，而灯现在从南边进来，连成一列耐心的队伍，每一盏都是某个人，有人接，或者没有。

21:52，一盏灯从琥珀色里升起，慢慢地，重型机都是这样，往北爬升，然后开始长长地往东转，朝大西洋，朝一座城市，它到那里的时候，这里天还黑着。你一路看着它，直到它成为群星之中的一颗星，然后不是了。你底下四十五层，在一间没人要的房间里，风扇吸了一口气又降下去。笔记本电脑上，一笔闭合了。

```
10-30 21:52:31  预期    应验  +22 分
10-30 21:52:32  静
```

它知道有重型机在它的时窗内往东北爬升离场。它知道的就这些。你也是。

这是一个星期五。这是错开的那一周最后一夜。星期天两点会又变回一点，而你会在那个房间里，它也会。在那之前，没有什么该来。在上面这里，你一停下来不动，灯就会自己熄掉，而你有好一阵子不会停。
