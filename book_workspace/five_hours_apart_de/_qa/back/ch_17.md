## XVII. Gears [Zahnräder = gearwheels, lit. "tooth wheels"]

#### notes ch_17
- "Raum" as row label and as the code RAUM (ch_17.002 to .007): again cannot separate "room" from "space"; "Raum-s" and "den der Raum schrieb" read differently under each.
- "IRIS      wach  liest sie" (ch_17.004): "liest sie" can be "reads it (the message)" or "she reads"; the object is unclear.
- "Scheibe 1 s" (ch_17.005): "Scheibe" reads first as a (window) pane or disc; "Zeitscheibe" or "Takt" would make the time-slice sense clear.
- "über Wasser        über der Mitte" (ch_17.006): "über der Mitte" reads as "above the middle", not clearly "past the halfway point".
- Code "KLEIN" (ch_16) vs. lowercase "klein" here (ch_17.004, .006): inconsistent casing for what seems the same entity.
