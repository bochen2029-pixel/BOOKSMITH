# Font licenses — SIL Open Font License 1.1

Every typeface vendored in `fonts/` and `fonts/library/` is licensed under the
**SIL Open Font License 1.1**, which permits bundling, redistribution, and
commercial use — provided the license text accompanies the fonts. This folder
satisfies that condition: one `OFL_<Family>.txt` per family, fetched verbatim
from the canonical `google/fonts` repository (`ofl/<family>/OFL.txt`,
2026-07-11), each carrying that family's own copyright and Reserved Font Name
statement.

| Family | License file |
|---|---|
| Alegreya | OFL_Alegreya.txt |
| Cinzel | OFL_Cinzel.txt |
| Cormorant Garamond | OFL_CormorantGaramond.txt |
| Crimson Pro | OFL_CrimsonPro.txt |
| EB Garamond | OFL_EBGaramond.txt |
| Great Vibes | OFL_GreatVibes.txt |
| Inter | OFL_Inter.txt |
| JetBrains Mono | OFL_JetBrainsMono.txt |
| Libre Baskerville | OFL_LibreBaskerville.txt |

| Montserrat | OFL_Montserrat.txt |
| Oswald | OFL_Oswald.txt |
| Playfair Display | OFL_PlayfairDisplay.txt |

The fonts ship unmodified under their original names, so no Reserved Font Name
restriction is triggered. Note that **Georgia** (the interior body default on
Windows) is a Microsoft system font and is NOT — and cannot be — vendored here;
see `INSTALL.md` for choosing a vendored OFL body face instead.
