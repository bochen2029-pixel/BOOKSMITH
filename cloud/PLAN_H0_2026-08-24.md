## §0 · Bo's constraints, constitutional for this phase (verbatim intent)

1. **TAVUS = CARVE-OUTS, NOT INTEGRATION.** Uncertain API costs; leave the door open at exactly
   three touchpoints, wire nothing: (T1) **onboarding** — talking out the story/idea instead of
   the form; (T2) **revision** — talking instead of typing todo lists; (T3) **support** — the
   escalation step BEFORE Bo gets an email/call/ticket. Design rule: each touchpoint is a named
   SEAM (a source/mode field + a compile-to-text step), so Tavus later means adding a source,
   never rearchitecting. No Tavus keys, no Tavus calls, no Tavus UI in H0.
2. **NO CONNECTOR/SCANNER.** The "small connector that scans and finds materials" idea is ON HOLD
   (complexity + privacy/legal). H0 ingests ONLY what the user deliberately hands over:
   drag-and-drop uploads (live today). A future user-initiated Google-Drive-style OAuth picker is
   an acceptable LATER class; ambient scanning is not. (When that day comes, a harness in the
   container is the natural operator of it — out of H0 scope by definition.)
3. **MANUAL EDITING IS A FIRST-CLASS FEATURE.** The user can open a chapter and edit the words
   on the screen themselves — not everything is a prompt. Every manual save is tracked and
   attributed (**human edit vs AI edit**), internally at minimum (colored view later), because
   the authorship record "might become useful in different ways later" (it will: provenance,
   the passport, voice truth, and the human-authorship story).

## §2 · Adopted defaults under blanket GO (each reversible, flagged for Bo's veto)

- **D1 · Revision pricing (the open question from DESIGN_reentry_revisions §6.1):**
  **3 free AI revisions per ticket** (mirrors the outline-reroll cap; the alpha floor E-6 caps
  worst-case spend regardless), then a friendly "more revisions are coming as packs" wall.
  Paid packs = P2 with Stripe work. Manual edits + their rebuilds are **unmetered** (no model
  tokens; CPU only) — a nice honest line: *your own hands are always free.*
- **D2 · Human-edit voice policy:** structural gates stay HARD on manually edited units (H1 lock,
  placeholder scan, packaging); **voice lint downgrades to advisory on human-edited units** —
  an em-dash a human typed is their voice, not an AI tell (the exact doctrine already lived in
  the mom's-book 破折号 rule). AI re-rolls of that unit re-enter the hard voice gate.
- **D3 · Manual-edit versioning:** append-only, kit-law: every save = `manuscript/drafts/
  {id}_v{N}_human.md` + promote to current + a row in the unit's provenance ledger
  (`registry/authorship_ledger.jsonl`: ts, unit, actor human|ai, source verb, unified diff stats,
  sha256 before/after). The colored diff VIEW is later; the DATA is complete from day one.
- **D4 · Editor v1 shape:** per-chapter plain-text editor (textarea) over the unit body;
  **the H1 title line is locked** (scan_manuscript requires byte-match with config) and photo/
  caption lines are visually fenced with "keep photo lines as they are" guidance + a structural
  check on save that refuses a save which deletes/mangles an image path (friendly message,
  nothing lost — the draft is kept). WYSIWYG/block editor = later polish.

## §3 · The build sequence (laps; image changes batch into ONE a12 lap)

**Lap A — kit-side (Windows-testable, no deploy):**
A1 `_tools/engine.py` + ops: `revise_unit` entrypoint (re-draft ONE unit from its contract +
   revision note → GATE-3 loop → promote → hash cascade re-derives assemble/produce/verify only).
A2 `_tools/authorship_ledger.py` (tiny lib): append/read the provenance ledger; wire into
   promote paths (ai) and the new manual-save path (human).
A3 `_tools/manual_edit.py`: validate + apply a human unit-body save (H1 lock, image-line guard,
   UTF-8, atomic, append-only version, ledger row, mark formats stale).
A4 `_tools/cover_gen.py` `--backend workers-ai` (FLUX via CF token) + provenance
   `method:"workers_ai_flux"` + schema/gate extension + must-fail battery rows; falls back to
   hypergen on API failure (fail-open to the $0 floor, loudly logged).
A5 `_tools/vision_verify.py` `--backend claude-api` (Haiku vision, ≤2000px guard kept).
A6 lint: voice-advisory mode for units whose latest ledger actor is human (D2).

**Lap B — shim (a12 image):**
B1 verbs: `GET /t/<id>/unit/<unit_id>` (body for the editor) · `PUT /t/<id>/unit/<unit_id>`
   (manual save → A3) · `POST /t/<id>/revise` {unit_id, note} (→ A1, busy-gated) ·
   `POST /t/<id>/rebuild` (production-only re-run, no drafting) · `GET /t/<id>/manifest`
   (workspace file list + sha256s, for full archive) · `POST /t/<id>/rehydrate` (accept files
   back into a cold container). All behind the existing busy-gate + auth discipline (a11c).
B2 image: rebuild BASE+cf together per lesson 7; push per lesson 19; rollout per lesson 20
   (quiet window, in-band marker `{"shim":"a12"}`).

**Lap C — worker + pages (site deploy):**
C1 full-workspace archive on ready/revised (manifest-driven, buffered puts per lesson 15,
   in-band `s.archive` receipt) + rehydrate-before-revise when container is cold.
C2 routes: `/api/book` (units list) · `/api/unit` GET/PUT (editor) · `/api/revise` (metered,
   3-free counter, stage ready→revising→ready) · `/api/rebuild` (unmetered) — all stage-gated
   + origin-gated + rate-limited like their siblings.
C3 raise.html: chapter list on ready → read view → **Edit** (D4 editor) + **Ask for a rewrite**
   (note box) per chapter; version history line ("edited by you · rewritten by the machine");
   plain-language status while revising.
C4 Tavus seams (T1/T2/T3): `tickets.intake_mode` default `form` · revise accepts
   `note_source` default `typed` · `SUPPORT_MODE` env default `ntfy` + a /help panel with the
   self-serve copy and the named escalation hook. Fields + stubs only (§0.1).
C5 support ladder copy (stalled page: what happened, what happens next, the un-burned credit line).

**Lap D — proof:** the live battery: sim ticket → build → manual edit (verify ledger row human +
free rebuild + gates) → AI revise ch (verify cascade only re-derived the suffix + counter
decrement + budget) → eviction test (cold container → rehydrate → revise) → download all
formats → archive receipts. Then Bo's phone pass.
